# 《護國 評論集（台-華）》電子書 Web Reader (GitHub Pages)

本專案將杜信龍 (Tō͘ Sìn-Liông) 著作《護國 評論集（台-華）》轉製為現代化、響應式（Responsive）、高質感的 **GitHub Pages 線上電子書**，風格與體驗對齊 [七字孽電子書](https://sinliongtoo.github.io/Ebook_Chhit-ji-giat-siongsinpan_chhiukia/)，並全面升級 240 篇政論長文的檢索與閱讀體驗。

## ✨ 核心特色與功能

1. **台語羅馬字 / 漢字排版支援**：
   - 內建台灣開源字型 **芫荽字體 (Iansui)**（透過 jsDelivr CDN 動態加載）與花園明朝 (HanaMin)、Noto Serif TC。
   - 完整支援台語白話字（POJ）與教育部台羅拼音特殊符號與變音符號（如 `ê`, `o͘`, `ō`, `á`, `à`, `â`, `ā`, `̍`, `ⁿ`）。
2. **即時全文/標題/日期搜尋**：
   - 側邊欄頂部設有即時搜尋框，輸入關鍵字即刻過濾 240 篇章節。
3. **主題分類快速切換**：
   - 設有 `全部`、`國安 (100)`、`社會 (62)`、`母語 (55)`、`雜文 (23)` 膠囊分類標籤，一鍵過濾篇目。
4. **直覺閱讀導航**：
   - 每篇文末均提供「← 上一篇」、「📑 索引目錄」、「下一篇 →」按鈕。
   - 支援鍵盤左右方向鍵（`←` / `→`）切換章節，`ESC` 鍵關閉側邊選單。
   - 分類文章表格（索引）支援直接點擊標題無縫跳轉至該篇文章。
5. **深淺模式與字體調整**：
   - 右上角常駐主題切換（🌙 深色 / ☀️ 淺色），自動記憶使用者的閱讀習慣。
   - 提供 `A-` / `A+` 字體大小無級調節功能。
6. **移動裝置最佳化**：
   - 手機與平板自動切換為全螢幕抽屜式選單（Drawer），點選後自動收合，閱讀舒適無干擾。
7. **超高解析度向量封面**：
   - 由 `封面_A5_148x210mm.pdf` 以 288 DPI 原生渲染高解析度封面（1679 × 2382 px）。
8. **📚 專屬台語字典模式 (Tâi-gí Sû-tián)**：
   - 專門針對**台語文、全羅、漢羅文**設計，收錄杜信龍老師作品 8,139+ 條詞目。
   - 支援**漢字、白話字 (POJ)、教育部台羅 (Tâi-lô)、數字調 (tai5-gi2) 與無調號模糊搜尋**。
   - 提供 A 到 Z 羅馬字字首索引、出現頻率／字母排序、例句出處展開與真人/TTS 語音發音。
   - 內建一鍵外連：【教育部臺灣台語常用詞辭典】、【ChhoeTaigi 台語辭典】、【iTaigi 華台對照】。
   - 閱讀篇章時，選取任何台語字詞即可呼叫即時查詞氣泡快速查詢。

## 🚀 如何發布至 GitHub Pages

### 步驟 1：初始化 Git 並提交檔案

在專案目錄下開啟 PowerShell 或 Terminal：

```bash
git init
git add .
git commit -m "feat: 初版發布《護國 評論集》GitHub Pages 電子書"
```

### 步驟 2：推送到 GitHub 遠端儲存庫

在 GitHub 上建立一個新的公開儲存庫（例如 `Ebook_Ho-kok` 或自訂名稱），然後執行：

```bash
git branch -M main
git remote add origin https://github.com/<你的GitHub帳號>/<你的儲存庫名稱>.git
git push -u origin main
```

### 步驟 3：在 GitHub 開啟 Pages 功能

1. 進入你的 GitHub 儲存庫頁面，點選 **Settings**（設定）。
2. 在左側選單點選 **Pages**。
3. 在 **Build and deployment** > **Source** 選擇 **Deploy from a branch**。
4. 在 **Branch** 選擇 `main` 分支，資料夾選擇 `/ (root)`，按下 **Save**。
5. 等待 1~2 分鐘，GitHub 會顯示發布網址：
   `https://<你的GitHub帳號>.github.io/<你的儲存庫名稱>/`

## 💻 本地端預覽方式

無需安裝任何伺服器軟體，直接使用瀏覽器雙擊打開 `index.html` 即可瀏覽！

若需透過本機 HTTP 伺服器預覽：
```bash
python -m http.server 8000
```
然後在瀏覽器網址列輸入：`http://localhost:8000`
